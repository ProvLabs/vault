* Stopped mirroring internal NAV entries into the marker module. `UpdateVaultNAV` previously set the chain-wide marker NAV for the denom it priced, on markers a vault holds no permission on. Internal NAV entries are now written to the vault's own table only. The vault's share denom remains the single marker NAV the module publishes, set during reconciliation on the marker the module creates and holds grants on. An internal NAV volume beyond the marker NAV `uint64` range is no longer rejected, since nothing publishes it [PR 264](https://github.com/provlabs/vault/pull/264).
