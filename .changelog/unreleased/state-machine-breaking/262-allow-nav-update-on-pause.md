* Allowed `UpdateVaultNAV` and `RemoveVaultNAV` while a vault is paused, so an operator can pause, reprice held assets, and unpause as one sequence with user swaps closed for the whole span. Repricing a held asset during a pause now restates `PausedBalance`, which a paused vault answers every valuation query from, so the frozen value never reports a price the NAV authority has superseded and unpausing does not move the value a second time [PR 262](https://github.com/provlabs/vault/pull/262).
