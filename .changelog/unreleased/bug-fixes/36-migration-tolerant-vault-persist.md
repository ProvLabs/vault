* Stop the v1->v2 migration from halting the chain when a legacy vault fails the current `VaultAccount.Validate()`. Such a vault is now paused (zeroing its current interest rate and clearing its accrual queue entries) and persisted with the tolerated error on `EventVaultPaused.forced_error`, instead of aborting the upgrade handler on every node [#36](https://github.com/provlabs/vault/issues/36).
