* Restricted vault creation to governance: `MsgCreateVaultRequest` is now signed by the `authority` field, which must be the governance module account, so a vault can only come into existence through a passed governance proposal. The `admin` field is retained and designates the vault administrator chosen by the proposal, so it no longer has to be the signer. Any other signer is rejected with an unauthorized error [PR 265](https://github.com/provlabs/vault/pull/265) [PR 265](https://github.com/provlabs/vault/pull/265).
